About

I design the board, write the firmware, run the fleet, and ship the app. One person, whole stack: schematic and PCB layout, embedded C++ on cellular hardware, over-the-air updates, image recognition, and the web and mobile software customers actually touch.

Founder of OcuTrap, where all of that runs in production on live hardware in the field.

§2

OcuTrap, the flagship

A cellular smart trap for wildlife control. It watches its own doorway with time-of-flight ranging, photographs what walks in, closes the door with a motor it controls to the millimeter, and reports home over LTE.

Every layer is built in house: the PCB, the embedded C++ firmware, the camera module, the OTA release pipeline, the image recognition that identifies the animal, and the real-time web and mobile app that runs on Convex.
